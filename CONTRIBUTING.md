# Contributing

Thanks for wanting to help — any contribution is really appreciated, big or small.

## Ways to help

- Add or improve problems for a topic
- Suggest learning resources or project ideas
- Fix bugs or improve the web app
- Improve docs, explanations, or fix typos
- Open an issue with feedback or questions

## Workflow

1. Fork the repo and create a branch: `git checkout -b my-change`
2. Make your change (for the app: `cd web && npm install && npm run dev`)
3. Run `npm run lint` inside `web/` if you touched app code
4. Open a pull request describing what and why

Keep PRs focused — one idea per PR is easiest to review. For larger changes, open an issue first so we can discuss.

## Guidelines

- Be kind and patient. We're all here to learn.
- Don't add problems or solutions copied from paid or copyrighted sources.
- Original explanations beat links; links beat nothing.
