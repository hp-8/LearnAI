# LearnAI

A structured, open roadmap for learning all of AI — from math foundations and classical symbolic AI to deep learning, NLP, computer vision, RL, robotics, GenAI, agents, and AI safety.

## Why

I believe in people learning together. Learning alone is slow and easy to quit; learning in the open, sharing problems, solutions, and projects, makes everyone better. That's why I'm building this project — a free path anyone can follow, improve, and build on.

## How it works

Every topic follows the same loop:

1. **Learn** — core concepts
2. **Solve** — hands-on problems (Easy / Medium / Hard), from scratch, NumPy before frameworks
3. **Build** — one shippable project
4. Tick it off, move to the next topic

Progress is tracked per problem in your browser (localStorage). See [ROADMAP.md](ROADMAP.md) for the full curriculum.

## Project structure

```
index.html    # original single-file prototype
ROADMAP.md    # full curriculum: phases, topics, problems, projects
PRODUCT.md    # product goals and constraints
web/          # Next.js app (the version being actively built)
```

## Run locally

```bash
cd web
npm install
npm run dev
```

Open http://localhost:3000. Or just open `index.html` in a browser for the prototype.
