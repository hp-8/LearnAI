# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Next.js / React (user choice). Currently a single static `index.html` prototype; to be migrated.

## Users

Primary: Harsh, self-learner working through all of AI (ML, DL, CV, NLP, RL, robotics, GenAI, agents, classical/symbolic AI, data science, AGI/safety). Later: shared publicly with other self-learners.

## Product Purpose

Structured self-study path for AI. Loop per topic: learn concepts → solve problems → build a project → move on. Success = steady visible progress through every field, with shipped projects.

## Positioning

Inspired by NeetCode's roadmap-plus-problems model but for AI broadly, not interview DSA. Must not copy NeetCode's look.

## Capabilities and Constraints

- 14 main topics in a dependency tree; each has subtopics (some marked elective), 1–3 problems per subtopic with Easy/Medium/Hard difficulty, one build project per topic.
- Progress tracked per problem, persisted in localStorage.
- Planned (not built): in-browser Python editor with tests (CodeMirror + Pyodide).
- No video solutions, no verified external problem links yet.

## Evidence on Hand

Topic/problem data in `index.html`. No testimonials, users, or metrics; do not fabricate.
